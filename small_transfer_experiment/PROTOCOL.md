# Frozen external test and CPU timing protocol

Frozen on 2026-11-02 before reading SMALL test image pixels or evaluating scores. This is a user-requested transfer assessment, not confirmatory evidence that the cross-capture references are pixel-aligned.

* Dataset: existing author SMALL v1.0.0 archive, DOI 10.17632/vnz4gcw8wk.1, CC BY 4.0. Evaluate all 50 published test pairs / 37 scene IDs once; no filtering, tuning or choosing checkpoints using this split. Images remain in the existing E: archive, with release SHA256 checks for each used member. Training history of the external checkpoints is not exhaustively verifiable.
* Resize both input and reference identically by Pillow Lanczos, preserving aspect ratio with longest side 600 pixels, then top-left crop both dimensions to a multiple of 12. Reject a pair if native dimensions differ. These resized scores are not official native-resolution leaderboard scores. Disclose any failures rather than selectively omit pairs.
* Fixed checkpoints: official Zero-DCE++ Epoch99, SCI CVPR medium, RUAS journal lol; reuse the project's existing loaders/checkpoint SHA and source checks. Inference uses one CPU thread and batch one, no training or adaptation. Clip model output to [0,1].
* Fixed global gate: input encoded RGB luminance mean, threshold 0.18 and temperature 0.04, unchanged from MILL; use the recorded project's fusion implementation with global_map=True. Never use test references in inference.
* Per pair report input, original output and gate float RGB PSNR (float64 MSE, data range 1), plus change gate-minus-original. Primary aggregate is equal pair mean; also report equal-scene mean and number of image regressions. Do not infer statistical significance or physical scene independence. Misregistration, capture/ISP differences, resizing, device/scene correlations and small sample limit interpretations.
* Separately time the existing global gate implementation on synthetic float32 RGB 600x400 arrays. Include array validation, luminance computation, blending, clipping and allocation; exclude file I/O and network model. One CPU thread, 10 warmups and 100 recorded calls, report median and p95 wall-clock time, hardware, software and current sharing conditions. It is a local CPU measurement, not mobile or end-to-end latency.
* One process at a time, with no GPU and availability checks between pairs. Preserve all raw metrics and failures; test data are never used to revise the operating point or exclusions.
